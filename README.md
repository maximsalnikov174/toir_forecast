toir_atu_fastapi

Важные детали:
1. Следует учесть, что при парсинге данных отчета в текущей реализации для
записей, крайнее ТО в которых закрыто "в будущем" происходит автоматическая
подмена даты проведения на 2025-01-01 (специально).
В дальнейшем следует выполнять накопление информации по ошибкам пользователя и
предоставлять для оперативного изменения.

2. Все существующие виды сервисного обслуживания обрабатываются парсером, но
при расширении от разработчика (либо администратора системы) будет требоваться
дополнить справочник новыми данными.




Порядок запуска:

Cоздать и активировать виртуальное окружение:  
```  
python -m venv venv  
```  

* на Linux/macOS
```  
source venv/bin/activate
```

* на windows  
```  
source venv/scripts/activate  
```  

Установить зависимости из файла requirements.txt:  
```  
python -m pip install --upgrade pip  
```  

```  
pip install -r requirements.txt  
```  

Создать файл .env в корне проекта с переменными окружения (есть в env.example):  


Применение миграций (работать только с ними), находящихся в /alembic/versions:
```
alembic upgrade head
```

Запуск приложения через терминал:
```
uvicorn toir_app.main:toir_app --host 0.0.0.0 --port 8000 --reload
```
