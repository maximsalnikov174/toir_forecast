toir_atu_fastapi

Важные детали:
1. Следует учесть, что при парсинге данных отчета в текущей реализации для
записей, крайнее ТО в которых закрыто "в будущем" происходит автоматическая
подмена даты проведения на 2025-01-01 (специально).
В дальнейшем следует выполнять накопление информации по ошибкам пользователя и
предоставлять для оперативного изменения.

2. Все существующие виды сервисного обслуживания обрабатываются парсером, но
при расширении от разработчика (либо администратора системы) будет требоваться
дополнить справочник новыми данными.




Порядок запуска:

1. Cоздать и активировать виртуальное окружение:
```
python -m venv venv
```

* на Linux/macOS
```
source venv/bin/activate
```

* на windows
```
source venv/scripts/activate
```

2. Установить зависимости из файла requirements.txt:
```
python -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

3. Применить миграции (работать только с ними), находящихся в /alembic/versions:
```
alembic upgrade head
```

4. Файл .env
Создать файл .env в корне проекта (директория toir_app) с переменными окружения (есть в env.example)

5. Запуск приложения через терминал:
```
uvicorn main:toir_app --host 0.0.0.0 --port 8000 --reload
```


после сборки оркестра выполнить:
```
docker-compose exec backend alembic upgrade head
```
